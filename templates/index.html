How the assistant works

01
The question arrives

Someone types something like "how many vans are free today?"

02
The app reads the database first

Driver count, van count, today's allocations and what's still unclaimed are pulled from SQLite.

03
The model answers from that state

The real numbers go to the model alongside the question, so the answer reflects the allocation table rather than a guess.
